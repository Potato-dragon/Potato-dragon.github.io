# Top5 Shorts policy site

This is the public website for Top5 Shorts, a personal tool that makes short "Top 5" gaming highlight videos with original commentary and posts them to its operator's own YouTube, Facebook, Instagram and TikTok accounts. It exists to host the Privacy Policy, Terms of Service and data deletion instructions that those platforms' developer apps require. It is served by GitHub Pages at https://potato-dragon.github.io/.
